3 Access tokenni yangilash POST

Access tugaganda (401) — refresh tokenni yuboring, yangi access (va yangi refresh) qaytadi.

So'rov
curl -X POST "{{ refresh_url }}" \
  -H "Content-Type: application/json" \
  -d '{"refresh": "<refresh>"}'
Javob
{{ refresh_example }}
